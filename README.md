# traineeHW

The console application includes three student trackers:

- `STUDYPLANNER` (also available as `STUDYTIMETRACKER`) — weekly study sessions and the 600-minute goal.
- `GRADETRACKER` — assignment and exam results with current grade calculation.
- `SCREENTIMETRACKER` — daily screen-time totals and productive/entertainment comparison.

Each tracker repeats its menu until its local `Exit` option is selected, then returns to the main command menu. Use the main `EXIT` command to close the application.
